# Patidar Homeopathic Clinic Website

This repository contains the website for Patidar Homeopathic Clinic, a responsive single-page application built with React, Vite, and Tailwind CSS.

## Project details
- Clinic name: Patidar Homeopathic Clinic
- Doctor: Dr. Lokesh Patidar
- Location: Mandsaur, Madhya Pradesh
- Services: Homeopathic treatment for chronic diseases, skin problems, thyroid issues, joint pain, and more
- Contact: +91 98266 23981, contact@patidarhomeoclinic.com

## Available scripts
- `npm run dev` - Start development server
- `npm run build` - Build production files
- `npm run preview` - Preview built production site
- `npm run lint` - Run ESLint checks
